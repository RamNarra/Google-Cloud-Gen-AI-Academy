Cohort 2: Introductory Session Summary

Overview

Following a massive response of over 200,000 registrations in Cohort 1, Google Cloud GenAI Academy APAC Edition Cohort 2 is officially launching! It runs from April to June 2026. Registrations close on May 28th.

Theme: Unified Data Analytics and Intelligence. You will learn to combine data pipelines, multimodal analytics, and autonomous agents to transform raw data into actionable intelligence.

Learning Tracks

The program features pathways simplified into one Student track and two Professional tracks. You start with Google Skill Labs, tackle workshops and Code Labs, clear an MCQ assessment, and advance to the Hackathon.

For Professionals (Choose one or both)

  • Track 1 - Conversational Agents: Learn how to build and use conversational agents within BigQuery to intuitively chat with your data and simplify data engineering.
  • Track 2 - AI-Assisted Data Science in BigQuery: Focus on building multimodal data science workflows combining structured and unstructured data using BQML, Gemini, embeddings, and algorithms directly within BigQuery.

For Students

  • Agent Development Kit (ADK): Learn to design and deploy both single- and multi-agent applications. The curriculum covers integrating AI frameworks with proper context management, sequential/parallel routers, and memory sessions.

Major Cloud Next 2026 Announcements Highlighted

  • Agentic Data Cloud Kit: Bring BigQuery and data services directly into your IDE (like VS Code or Cloud Shell) using intelligent agents that can build pipelines and analyze schemas.
  • Cross-Cloud Lakehouse: Access external data sources like S3 databases directly from BigQuery natively.
  • Spanner Omni: Graph data structure capabilities that can now run in air-gapped environments alongside vector support.
  • Looker AI Insights: Conversational dashboards and proactive anomaly detection injected right into your BI workflow.

Graduation & Rewards

By completing the required labs and MCQ testing, you will earn the prestigious GenAI Master Certificate, get access to the Elite Club alumni network, cash prizes, exclusive goodies, and qualify for the final hackathon phase!
